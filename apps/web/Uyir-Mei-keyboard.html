How this keyboard works

TAP

Any key types its base form instantly — a consonant like க / ಕ, or a vowel like அ / ಅ. No delay.

HOLD + DRAG DOWN

Strips the vowel — க் / ಕ್ (pulli / virama). The vowel keys now merge into this consonant until the next word.

HOLD + DRAG UP

Long-a shortcut — கா / ಕಾ directly, one motion.

HOLD (any consonant)

A radial dial appears around the key, positioned like the vowel pad: west→short/long u, east→short/long i, north-east→short/long e, north-west→short/long o, south-east→ai, south-west→au. Short drag = short vowel, drag further out = long vowel.

VOWEL PAD

The 7 vowel keys sit in one block, positioned as a compass, same layout in both languages. Drag any of them upward to get its long pair, where one exists.

LANGUAGE SWITCH

Tamil and Kannada share nearly identical phonology, so the same gestures and key positions work for both — only the glyphs change. Switching languages mid-word transliterates what you've already typed letter by letter instead of clearing it. A few Tamil letters (like ன) have no separate Kannada letter and fall back to the nearest match (ನ).

WORD RESET

After space, return, or punctuation, the vowel pad goes back to typing standalone vowels — the pulli merge only ever applies to the very next key.

SMART BACKSPACE

On a combined letter like கி / ಕಿ, the first tap strips it back to the pulli form; the second removes it fully. Plain letters delete in one tap.
